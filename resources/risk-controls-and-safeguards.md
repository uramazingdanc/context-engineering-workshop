# Operational Risk Controls

## Data Security & Row Level Security (RLS)

Unconstrained prompts can generate database tables without access controls. Facilitators should emphasize verifying RLS policies inside the Supabase view **before** launching applications to real users.

## Vendor Lock-in Prevention

Proprietary SaaS platforms can isolate source code. Lovable mitigates this via continuous bi-directional GitHub synchronization, exporting standard React, TypeScript, and Vite code.

## Context Window Stability

Excessive conversational prompting introduces context rot. Direct visual element selection isolates UI changes, preventing prompt bloat and preserving context window performance.
