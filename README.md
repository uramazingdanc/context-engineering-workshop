# Intro to Context Engineering
### From Strategic Prompting to Building Web Apps with Lovable & Low-Code AI

A 60-minute, browser-only workshop that takes participants with **zero coding experience** from basic prompting to publishing a live, database-backed web app — using structured "context engineering" instead of ad-hoc chat prompts.

- **Track:** Track 2 — AI & Applied Prototyping
- **Level:** Beginner to Intermediate (no coding, HTML/CSS, or web dev required)
- **Duration:** 60 minutes across 5 modules
- **Stack:** [Lovable](https://lovable.dev) (AI builder) · [Supabase](https://supabase.com) (Postgres backend) · GitHub (version control)
- **Cost:** 100% free tier — no credit card, API keys, or local install required
